ExamOps v0.2.0

本次更新
- 新增夜间模式和侧边栏模式切换按钮，自动记住选择。
- 新增启动开屏动画；系统开启“减少动态效果”时跳过动画。
- 每次启动后台检查 GitHub 更新，在“设置 → 关于”也可手动检查。
- 仅提醒更高版本、包含 Windows x64 安装包的正式 Release；点击后打开发布页，由用户下载和安装。

安装
下载 ExamOps_0.2.0_x64-setup.exe，适用于 Windows x64，按当前用户安装。内置文档处理程序、OCR 模型与 WebView2 离线安装程序。
旧版 0.1.0 预览安装包没有更新检查功能，需要手动下载本次安装包。
安装包未进行代码签名，Windows 可能显示未知发布者提示。

验证
前端 24 项单元测试、Rust 98 项测试（串行）及 clippy 通过。GitHub CI 的前端、Python、Windows Rust 和 Ubuntu Rust 检查全部通过。Windows 安装包构建成功；随包文档处理程序通过中文 Markdown、Word、PPT 和扫描 PDF 冒烟测试。界面已通过浏览器模拟 Tauri 接口的交互检查；未在用户环境执行安装或升级。

提供 SHA-256 校验文件。课程资料与现有数据库结构保持兼容，本次未改变学习业务逻辑。
