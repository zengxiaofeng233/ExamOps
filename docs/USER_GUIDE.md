# 使用指南

ExamOps 围绕“导入资料 → 学习 → 检验 → 复习”组织：AI 只依据你导入的资料讲解和出题，学习记录、掌握度和复习计划都保存在本机。安装和模型配置见 [安装与首次使用](INSTALL.md)。（截图中的 AI 内容来自本地模拟服务。）

## 1. 界面

![首页](images/home.png)

- **首页**：继续上次学习、今天要复习的内容（到期知识点、未解决错题、距考试天数）和各课程进度。
- **我的课程**：创建、编辑、删除课程；可设置考试日期。
- **课程页**的标签：

| 标签 | 用途 |
| --- | --- |
| 概览 | 当前学习步骤、上次的学习位置、复习与建议、知识点进度、考试日期、近两周学习记录 |
| 资料 | 导入、阅读、检索教材和课件 |
| 知识点 | 管理知识点、学习状态和掌握度 |
| 学习路径 | 安排学习顺序，逐步完成 |
| AI 学习 | 按章节讲解（从零学习 / 正常复习 / 考前冲刺），也可以讲解网课 |
| 测验 | AI 出题、作答、批改 |
| 复习 | 下一步建议、AI 复习建议、复习队列、错题本 |
| AI 问答 | 自由提问，回答标注来源 |
| 网课 | 保存网课链接、字幕、时间戳和笔记 |
| 笔记 | 与资料位置、章节、知识点关联的笔记 |

“设置 → 通用”中开启“启动时恢复上次的学习位置”后，重新打开 ExamOps 会回到上次所在的页面。

## 2. 资料

- **导入**：资料页点击“导入资料”，可一次选择多个 PDF、Word（.docx）、PPT（.pptx）、TXT、Markdown 文件。ExamOps 复制一份到数据目录，原文件不变。
- **解析**：自动识别章节（PDF 书签、Word 标题样式、PPT 每页标题、文字中的“第一章 / 1.1”等编号），提取图片；扫描页和图片中的文字由本地 OCR 识别。解析失败会显示原因，可点击“重新解析”；重新解析失败时保留原有结果。
- **阅读**：左侧目录按章节跳转；PDF 可以“显示原页面”对照排版；图片可以放大查看。阅读位置会被记住。
- **检索**：在“检索”框输入关键词（如“导数 几何意义”），可选在全部资料或当前资料中检索，点击结果跳到原文位置。
- 阅读时可以点击 **AI 讲解** 从零讲解当前章节，或 **记笔记** 记一条关联当前位置的笔记。
- 窗口较窄时，打开资料后左侧的资料列表会自动收起，点击检索框左边的 ≡ 可以重新展开。

## 3. 知识点

- **从章节标题生成**：把识别出的小节标题作为知识点，不需要 AI。
- **AI 提取**：选择章节，AI 阅读该章资料，整理出可以单独讲解和测验的知识点并标注重要程度（一般 / 重要 / 核心考点），结果自动去重。
- 每个知识点有三种状态：**未学**、**学过**（阅读、讲解、网课学习过）、**已掌握**（只能通过测验获得：掌握度达到 80% 且至少答过 2 道相关题目）。“学过”和“已掌握”分开记录。
- 可以标记“疑难”，针对单个知识点做小测或让 AI 讲解，也可以手动添加、编辑和删除。

## 4. 学习路径

- **新建学习路径**有三种方式：
  - **按章节生成**：按资料目录顺序为每章安排阅读、AI 讲解、回忆等步骤，可勾选“每章结束后加入一次小测”；
  - **AI 推荐**：AI 根据资料目录、网课、知识点状态和考试日期推荐，可以写下你的要求（如“两周内学完前三章，不看网课”）；推荐的每一步都会校验，只保留能对应到你资料的步骤；
  - **空白路径**：自己添加步骤。
- 路径有学习模式（从零学习 / 正常复习 / 考前冲刺），决定 AI 讲解步骤使用的方式。
- 步骤类型：阅读教材、阅读 PPT、观看网课、AI 讲解、知识点小测、主动回忆、复习旧知识、自定义任务。点击“开始”直接打开对应页面；完成 AI 学习或小测后步骤会自动完成，也可以手动完成、跳过或恢复。
- 拖动或使用上下箭头调整顺序；可以在任意位置插入、编辑、删除步骤。一门课程同一时间有一条“当前路径”，概览页会显示它的下一步；不用的路径可以归档。

## 5. AI 学习

选择学习模式和章节后点击“开始”。学习记录自动保存，下次从“学习记录”中继续。

- **从零学习**：AI 把章节分成若干部分（约 1500 字一段）逐段讲解，每段讲完停下来等你。可以直接追问，或使用：
  - 继续讲解下一部分 / 讲完了，总结全部内容；
  - 举个例子、换种方式讲讲、总结要点；
  - 跳过下一部分（已经会了）；
  - 点击分段列表中的任一部分，直接讲解它。
  讲完后点击“标记已学完”，本章知识点记为“学过”，关联的学习步骤完成。按“设置 → 学习与测验”中的设置，会提示你做一次小测。
- **正常复习**：AI 先出回忆题让你凭记忆作答，再逐题纠正补充；可以“再来一组复习题”。
- **考前冲刺**：精炼列出必考点、必背公式和典型题思路，优先补薄弱知识点；可以“讲一道典型题”。
- **网课**：在“网课”页点击“AI 学习这节网课”。AI 只根据已保存的字幕、文字稿、平台 AI 总结、笔记和时间戳讲解，不会凭链接猜测视频内容；只有 AI 总结时，会明确说明它只是摘要。

回答中的 **教材 / 补充 / 推导** 标签和 `[1]` 这样的编号表示内容来源，点击编号可跳到资料原文或对应的网课。

## 6. AI 问答

“新建对话”后直接提问。对话顶部可以切换：

- **上下文**：自动（资料较少时发送全文，较多时检索相关片段）、全文、检索；
- **资料范围**：全部资料或指定几份；
- **模型**：配置了多个模型时可切换。

回答以流式显示，可以随时“停止”（保留已生成的部分），也可以“重新生成”。回答末尾列出“资料来源”。网络中断、超时、接口报错时会显示原因，并提供“重试”。

## 7. 网课

“添加网课”填写名称、链接、关联章节，以及：

- **字幕 / 文字稿 / AI 总结**：支持手动粘贴，也可读取 B 站的字幕或 AI 总结；
- **学习笔记**：老师讲的重点、例题、你的疑问；
- **时间戳**：标记重点位置并可关联知识点，点击时间在浏览器中从该处播放（B 站、YouTube 支持）。

视频在浏览器中打开观看，ExamOps 不嵌入网站。

**B 站文字获取：** 填入完整视频链接或 `b23.tv` 短链接，且文字稿为空时，应用会在后台尝试获取字幕（优先中文），没有可读取字幕时再尝试平台 AI 总结。多分 P 视频按链接的 `p` 参数读取，未指定则读取 P1，不会抓取整套课程。获取期间仍可编辑、保存和切换页面。

部分字幕和总结需要登录。点击“扫码登录 B 站”，使用哔哩哔哩手机客户端扫码并确认；成功后会重试读取。登录凭据只保存在本机系统凭据管理器，不写入学习数据库、不发送给 AI；凭据管理器不可用时登录会报错，不回退明文保存。“清除登录”仅清除本应用保存的凭据，不影响浏览器。登录过期后重新扫码即可。

获取成功会显示来源和内容，空白文字稿自动填入；已有文字不会被覆盖，可以预览后点“追加到文字稿”。**点击“保存”后**，获取的文字才会用于 AI 学习。更换视频链接时，请检查已有文字是否仍对应原视频。只有 AI 总结时，内容可能不完整；自动字幕也可能存在识别错误。

B 站接口、账号权限、字幕开放情况或访问限制可能导致读取失败；这不会妨碍保存链接，仍可手动粘贴文字。接口实现参考：[扫码登录](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/login/login_action/QR.md)、[签名版字幕接口的验证记录](https://github.com/ymt200120/bili-subtitle/blob/main/docs/PROTOCOL.md)、[AI 总结接口](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/video/summary.md)。

## 8. 笔记

在“笔记”页新建，或在阅读资料时点击“记笔记”（自动关联当前页）。笔记支持 Markdown 和 LaTeX 公式（`$...$`），可以关联资料位置、章节或知识点，并通过“打开原文”跳回。

## 9. 测验

“测验 → 新建小测”：

1. **出题范围**：按章节、选知识点、待复习（从复习队列中选取到期、薄弱和学过未测的知识点）、错题重练（针对未解决的错题出变式题）。
2. **题目数量**与**题型**：单选题、判断题（自动判分），简答题、自由复述、情景应用题（AI 对照评分要点批改）。
3. 可选“允许跳过题目”（跳过的题按答错计入）。

题目只依据你导入的资料生成。作答进度自动保存，可以关闭后回来继续。交卷后：

- 客观题立即判分，主观题由 AI 批改并给出反馈；
- AI 批改失败（断网、接口报错）时，可以“重新 AI 批改”或对照参考答案自己评分；全部题目有分后才计入掌握度；
- 结果页显示得分、每个知识点的掌握情况、正确答案、解析和评分要点，可以“针对错题再练”或“AI 复习本章”。

## 10. 复习

- **掌握度**：每次测验按该知识点题目的平均得分更新（新结果与历史各占一半）。
- **间隔复习**：答得好，下次复习间隔逐渐变长（1 天 → 3 天 → 更长，最长 180 天）；答得不好，明天再复习。设置了考试日期时，间隔不超过距考试天数的一半，保证考前至少再复习一次。
- **复习页**：
  - **复习概况**：今日到期、薄弱知识点（掌握度低于 60%）、学过未测、未解决错题、已掌握；
  - **下一步建议**：按学习状态生成，可直接开始；
  - **AI 学习建议**：AI 根据掌握度、错题、复习计划和考试日期安排今天和接下来几天的复习，并列出建议优先复习的知识点；
  - **复习队列**：可以“开始复习小测”，或对单个知识点做小测、让 AI 带你回忆和纠错；
  - **错题本**：查看你的答案、解析和批改反馈，“重练错题”；之后某个知识点答得好，相关错题会自动标记为已解决。

## 11. 设置

| 分类 | 内容 |
| --- | --- |
| AI 模型 | 添加 / 编辑 / 删除模型，测试连接，设为默认；填写接口地址及 API Key 后点击“获取模型”，可从服务商返回的列表选择模型，也可手动填写（本地服务可不填密钥；列表接口不可用时仍可手动输入）；上下文策略（自动 / 全文 / 检索、检索片段数、携带历史轮数）；Token 用量统计 |
| 通用 | 启动时恢复上次的学习位置 |
| 学习与测验 | 什么时候建议做小测（每学完一个知识点后 / 每学完一章后 / 仅手动开始）、每次题目数量、是否允许跳过、默认题型 |
| 数据与存储 | 查看并打开当前数据目录；更改存储位置（下次启动迁移，可取消）；迁移成功后确认清理旧副本 |
| 关于 | 检查更新、版本、许可证、开源许可、隐私说明 |

启动时会后台检查 GitHub 正式 Release；也可以在“设置 → 关于”点击“检查更新”。只有版本号更高且已上传对应 Windows x64 安装包时才提示。点击“下载更新”后会显示下载进度，期间可以继续使用应用；签名校验成功后点击“安装并重启”，确认后才会关闭应用并启动安装。请先保存正在编辑的内容、等待 AI 回答完成；资料正在处理时会阻止安装，处理完成后可重试。更新保留现有数据和设置。

“稍后提醒”只关闭本次顶部提示，下载继续进行，可在“设置 → 关于”继续操作。下载或校验失败可重试，也可点击“手动下载”打开对应 GitHub 页面。下载包暂存在当前进程内，关闭应用后需重新下载。自动检查失败不弹窗，手动检查失败会显示原因。v0.2.3 及更早版本仍需手动安装一次支持应用内更新的新版。

## 12. 隐私

- 没有账号，没有云端存储；课程资料、学习记录和设置只保存在本机的数据目录。
- 检查更新会连接 GitHub 获取公开版本信息，不上传课程资料、学习记录或 API Key。
- 只有在你使用 AI 功能时，相关资料片段和问题才会发送到你自己配置的 AI 接口；ExamOps 不经过任何中转服务器。
- API Key 优先保存在 Windows 凭据管理器中，界面只显示首尾几位。
