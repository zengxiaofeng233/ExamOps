# 安装与首次使用

本文面向使用 ExamOps 的同学。安装包已经包含运行所需的一切（界面运行时、文档处理程序、本地 OCR 模型），**不需要安装 Python、Node.js 或任何开发环境**。

## 1. 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10（1803 及以上）或 Windows 11，64 位 |
| 磁盘 | 建议预留 1 GB 以上空间（程序、OCR 模型和你导入的资料副本） |
| 内存 | 4 GB 以上；扫描版 PDF 的 OCR 会占用较多 CPU |
| 网络 | 只有使用 AI 功能时需要能访问你配置的 AI 接口；导入、阅读、检索、笔记都可离线使用。使用本机模型（Ollama、LM Studio）时可完全离线 |
| AI 接口 | 任何兼容 OpenAI Chat Completions 的服务，需要你自己的 API Key（BYOK） |

## 2. 安装

1. 获取安装包 `ExamOps_<版本>_x64-setup.exe`（由项目的“Windows installer”构建流程或 `npm run tauri:build` 生成）。
2. 双击运行。默认安装到当前用户目录，**不需要管理员权限**。
3. 如果电脑上还没有 Microsoft Edge WebView2 运行时，安装程序会使用内置的离线安装包自动安装（Windows 11 已自带）。
4. 安装包目前没有代码签名，Windows SmartScreen 可能提示“已保护你的电脑 / 未知发布者”：点击 **更多信息 → 仍要运行**。
5. 安装完成后，从开始菜单或桌面快捷方式打开 **ExamOps**。

> 个别杀毒软件可能把文档处理组件（由 PyInstaller 打包的 `examops-parser.exe`）误报为可疑程序。它只在本机解析你导入的文件、不联网；如被拦截，请将安装目录加入信任。

## 3. 首次设置

### 3.1 配置 AI 模型

1. 打开 **设置 → AI 模型 → 添加模型**。
2. 选择服务商预设（DeepSeek、OpenAI、通义千问、智谱 GLM、Kimi、硅基流动、Ollama 本机），或手动填写：
   - **接口地址（Base URL）**：填写到 `/v1` 一级即可，例如 `https://api.deepseek.com/v1`，`/chat/completions` 会自动补全；
   - **模型名称**：例如 `deepseek-chat`、`qwen-plus`；
   - **API Key**：在服务商控制台创建；本机模型（Ollama、LM Studio）可以留空。
3. 点击 **测试连接**，成功后保存。可以添加多个模型并“设为默认”，对话中也可以临时切换。
4. 展开“模型参数与 Token 预算”可以调整上下文预算、最大输出、温度和超时；服务商支持时勾选“接口支持 JSON 模式”，出题和提取知识点会更稳定。
5. 在同一页的“上下文策略”中可以设置 AI 回答时能看到多少资料（自动 / 全文 / 检索）。

API Key 保存在 Windows 凭据管理器中（控制面板 → 凭据管理器 → Windows 凭据，名称形如 `model-profile-1.com.examops.app`），界面只显示首尾几位；凭据管理器不可用时会保存在本机数据库，并在模型列表中标注“密钥本地保存”。

### 3.2 开始一门课程

1. **我的课程 → 创建课程**，填写名称；可以顺便设置考试日期。
2. 在课程的 **资料** 页导入教材、讲义、PPT、Word、TXT 或 Markdown，等待解析完成（扫描版 PDF 需要 OCR，速度较慢）。
3. 打开 **知识点** 页，点击“从章节标题生成”或“AI 提取”。
4. 在 **学习路径** 页按章节生成一条路径，或直接到 **AI 学习** 页选择章节开始学习。

更多用法见 [使用指南](USER_GUIDE.md)。

## 4. 数据位置、备份与迁移

- 学习数据默认保存在本机 `%APPDATA%\com.examops.app`，也可以更改到其他磁盘（在 **设置 → 数据与存储 → 打开数据目录** 中打开当前实际位置）。
  - `examops.db`：课程、知识点、学习记录、对话、小测等；
  - `documents\`：导入资料的副本和从中提取的图片（你的原文件不会被修改或移动）；
  - `cache\`：可再生的页面预览缓存，可以随时删除。
- **更改位置**：在 **设置 → 数据与存储 → 更改存储位置** 中选择本机磁盘上的空文件夹并确认。等待导入、解析、AI 生成等任务完成，关闭所有 ExamOps 窗口，再重新打开；启动期间复制并校验数据库、资料副本、提取图片和预览缓存，数据较多时请耐心等待。确认后、重启前仍使用原目录，可以取消迁移。新目录不能与原目录相同或互相包含，不支持网络目录、符号链接和目录联接。
- **释放旧空间**：迁移成功后确认资料和学习记录正常，再在同一页面点击 **清理旧数据**。仅删除已迁移且未变化的应用数据，原始导入文件和其他文件不动；旧目录出现新增或修改的数据时拒绝清理。未确认清理前，新旧两处都会占用空间。
- **迁移失败**：原数据保留，关闭错误提示后重新打开即可继续使用原目录。目标中未完成的副本不会自动删除，请手动检查后处理。自定义目录失联或缺少数据库时会停止启动并提示恢复目录，不会自动创建空数据库。
- **备份**：关闭 ExamOps，复制当前数据目录即可。**恢复 / 换电脑**：安装 ExamOps 并关闭它，将备份中的 `examops.db`、`documents`、`cache` 放到该电脑的数据目录；不要用其他电脑的 `storage-location.json` 覆盖本机配置。换了 Windows 用户名也没关系，资料和图片会在新位置被找到。
- 默认 AppData 目录仍保存 `storage-location.json`（位置及迁移校验信息）和进程锁；Windows、WebView2 等运行时文件也仍可能占用系统盘，迁移不代表 C 盘完全零占用。
- API Key 不在数据目录中，换电脑后需要在设置里重新填写。
- 新版本会自动升级数据库结构并保留数据；请不要用旧版本打开新版本升级过的数据（旧版本会拒绝打开以保护数据）。

## 5. 卸载

**设置 → 应用 → 已安装的应用 → ExamOps → 卸载**。卸载程序默认保留数据目录，方便重新安装后继续使用；如需彻底删除，在卸载时勾选删除应用数据，或手动删除 `%APPDATA%\com.examops.app`。保存在凭据管理器中的 API Key 不会随卸载删除：建议卸载前先在 **设置 → AI 模型** 中删除模型配置（会同时删除密钥），或之后在凭据管理器中删除以 `.com.examops.app` 结尾的凭据。

自定义磁盘上的数据目录不由卸载程序自动清理。如使用过自定义位置，卸载前请记下路径并备份；删除默认 AppData 配置后，重新安装不会自动找回自定义位置。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示“无法连接到 AI 服务” | 检查网络和代理；确认接口地址正确（多数服务需要以 `/v1` 结尾）；本机模型需先启动 Ollama / LM Studio |
| HTTP 401 | API Key 错误、过期或没有该模型的权限 |
| HTTP 404 | 接口地址或模型名称写错 |
| HTTP 429 | 请求太频繁或账户余额 / 额度不足 |
| “AI 服务响应超时” | 网络慢或模型负载高；可在模型高级设置中延长超时时间 |
| 回答被截断 | 在模型设置中调大“最大输出” |
| 出题时提示回答被截断 | 减少题目数量，或调大“最大输出” |
| 导入 `.doc` / `.ppt` 失败 | 旧版 Office 格式不支持，请另存为 `.docx` / `.pptx` |
| 加密 PDF 无法导入 | 先在 PDF 阅读器中移除密码后再导入 |
| 扫描版 PDF 导入很慢 | OCR 在本机逐页识别，属于正常现象；可以先导入文字版资料 |
| 章节识别不准 | 在资料页点击“重新解析”；带书签的 PDF、使用标题样式的 Word 识别效果最好 |
| 想清空页面预览占用的空间 | 关闭 ExamOps 后删除数据目录中的 `cache` 文件夹 |
